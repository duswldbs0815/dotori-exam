### B. PDF 안에서 서로 맞지 않거나 애매한 부분

| # | 항목 | 내용 | 관련 문서 |
|---|---|---|---|
| B1 | 반 전체 집계 우선순위 | 3장 교사 리포트 화면과 5장 API(`GET /report/class`)에는 있으나 4장에서는 P2(발표에서 설명만) | 03, 04, 05 |
| B2 | 슈퍼스쿨 "링크" vs "연동" | 2장은 "바로가기 링크 추가 (API는 확장)", 9장 시연 1단계는 슈퍼스쿨 바로가기 사용, 4장은 "슈퍼스쿨 연동"을 P2로 둠. 링크만은 P0/P1로 만들지, 시연에서 어떻게 보여 줄지 | 01, 04, 09 |
| B3 | 개요·성찰지가 P1인데 시연 필수 흐름에 포함 | 4장은 "개요 단계 / 성찰지 단계"를 P1로 두었으나 9장 시연 2·5단계에서 사용. 또 질문 시 개요 항목 ①~④ 선택(`outlineItem`)은 P0 흐름에 들어감 | 04, 09 |
| B4 | 차단 판별 단계 | 5장 `/ask`는 "차단 판별 → 답변 생성"을 별도 단계로 적었지만 7장 ①은 "답변 + 차단 (하나로 처리)". 구현은 LLM 1회 호출로 봄 | 05, 07 |
| B5 | 차단된 질문의 기록 범위 | 차단 시 도토리 차감은 없음이 확실하나, 분류(②)·직전 글 저장·`acornNo` 부여·학생 "나의 질문 기록" 표시·교사 메모 표시 여부가 불명확 | 02, 03, 05, 06 |
| B6 | 차단 확인창 순서 | "도토리 1개를 사용할까요?" 확인창은 차단 판별(서버) 전에 뜸. 차단되면 확인 후 차감 없이 되돌리는 흐름인지 | 02 |
| B7 | `[BLOCKED]` 표시 | 학생 화면·`answer` 저장값에서 `[BLOCKED]` 줄을 제거하는지 | 07 |
| B8 | 분류 `reason` | 7장 ② 출력에는 `reason`이 있으나 6장 JSON에는 필드가 없음 | 06, 07 |
| B9 | 선택 위치(시작·끝) | 8장은 시작·끝 위치로 저장하라고 하나 6장 JSON에는 `selectedText`만 있음 | 05, 06 |
| B10 | 본인 확인 기록·첫 글 | 5장 `/exam/start`가 저장하지만 6장 JSON에 필드 없음 | 05, 06 |
| B11 | 개요 항목 이름 vs 내용 | 3장 개요 4항목은 고정 이름(주제·배경지식 / 문법·어휘 / 해석과 근거 / 비평과 고쳐쓰기), 6장 `outline`은 학생이 쓴 내용("이별을 대하는 화자의 태도" 등). 두 정보를 어떻게 함께 저장할지 | 02, 06 |
| B12 | "스스로 작성" 정의 | 작성 경로 3종 중 "스스로 작성"은 7장 ③ 판정 대상에 없음. 질문 직후 새로 생긴 문장이 아닌 문장 전부로 볼지 | 03, 07 |
| B13 | 시험 생성/선택 기능 | 9장 1단계 "교사가 수행평가를 연다"와 6장 `exam` 정보가 있으나, 시험을 만드는 화면·API는 4·5장에 없음. 시연용으로 고정값을 쓸지 | 05, 06, 09 |
| B14 | "AI 3가지 역할"의 범위 | 2장 표의 ④ LLM 역할(답변/차단/분류)과 7장 지시문 3개(답변+차단/분류/작성 경로)가 1:1로 맞지 않음 | 01, 07 |
| B15 | 학생 B "고쳐쓰기 집중" | 분류 stage "고쳐쓰기"인지 개요 ④ "비평과 고쳐쓰기"인지 | 09 |
| B16 | 메모 위치 추적 | 질문 후 글이 바뀌면 제출 글에서 메모를 어디에 붙일지 | 03 |

### C. 요청서·저장소와 PDF의 차이

| # | 항목 | 내용 |
|---|---|---|
| C1 | 원본 PDF 경로 | 요청된 `docs/source/도토리시험지_구현계획.pdf`가 저장소에 없었음. `~/Downloads/도토리시험지_팀공유.pdf`(5쪽, 제목 "도토리 시험지 — 해커톤 구현 계획")를 같은 문서로 보고 해당 경로로 복사함. **최종본이 맞는지 확인 필요** |
| C2 | 손그림 위치 | 요청서에는 "3쪽 손그림"으로 되어 있으나 실제로는 PDF **2쪽**에 있음 (3장 화면 설계가 2쪽에서 시작) |
| C3 | 루트 `README.md` | 이전 기획 기준: 교사 시험 만들기(문항·정답·채점 기준), AI 가채점, 교사 점수 확정, 보고서 PDF, 붙여넣기·창 이탈 기록, `/api/chat`·`/api/snapshots` 등. PDF 5장 API(`/exam/start`, `/ask`, `/draft` …)와 경로·범위가 다름 |

| C5 | 기술 스택 | 저장소는 Next.js 16 + React 19. PDF 제안(React/Node) 범위 안이지만, 저장 방식(Supabase vs JSON 파일)은 결정 필요 |
