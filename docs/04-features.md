## 완료 기준 체크리스트

> PDF 설명(3·4·5·7·9장)에서 도출한 기준입니다. PDF에 없는 세부 기준은 TBD로 표시했습니다.

### P0-1. 글쓰기 + 질문창

- [ ] 학생이 텍스트 편집 영역(글쓰기 창)에 글을 쓸 수 있다
- [ ] 글을 드래그해 선택하면 선택한 글과 함께 질문을 보낼 수 있다
- [ ] 선택 위치가 텍스트의 시작·끝 위치로 저장된다 (8장)
- [ ] 질문할 때 개요 항목(①~④)을 고를 수 있다 (3장)
- [ ] 화면 배치: 왼쪽 글쓰기 창 / 오른쪽 위 질문 쓰기 / 가운데 나의 질문 기록 / 아래 도토리 창고
- [ ] 글을 선택하지 않고 질문하는 경우의 처리: TBD(확인 필요)

### P0-2. 도토리 차감 + 창고 애니메이션

- [ ] 질문 전 "도토리 1개를 사용할까요?" 확인창이 뜬다
- [ ] 사용하면 도토리가 정확히 1개 차감된다 (질문 1번 = 1개)
- [ ] 창고의 도토리가 넘어지는 효과가 보인다
- [ ] 차감은 서버 `/ask` 처리의 마지막 단계에서 일어난다 (5장)
- [ ] 도토리 총개수 상한 / 0개일 때 동작: TBD(확인 필요, 11장 남은 결정)

### P0-3. AI 답변 (3문장 제한)

- [ ] 서버가 LLM을 호출해 답을 받아 학생 화면에 표시한다
- [ ] 7장 지시문 ①을 원문 그대로 사용한다
- [ ] 답이 3문장 이내다 (`maxAnswerSentences: 3`)
- [ ] 학생 글의 문장을 대신 고쳐 쓰지 않는다
- [ ] LLM이 3문장을 넘겨 답한 경우 서버에서 자르는지: TBD(확인 필요)

### P0-4. 대신 작성 차단

- [ ] 글·문단을 대신 써 달라는 요청에 답 대신 되묻기 문구를 보여 준다
- [ ] LLM 응답 첫 줄 `[BLOCKED]`로 차단을 판별한다
- [ ] 차단 시 도토리가 차감되지 않는다 (시연: "비평문을 써 주세요" → 차단, 도토리 그대로)
- [ ] 차단된 질문이 `blocked: true`로 기록된다 (반 전체 "차단된 요청 수" 집계용)
- [ ] 학생 화면에 `[BLOCKED]` 표식 자체는 노출하지 않는다: TBD(확인 필요 — PDF 명시 없음)

### P0-5. 흔적 저장

- [ ] 질문마다 다음이 저장된다: 위치, 시간, 질문, 답, 직전 글, 직후 글
- [ ] 직전 글은 `/ask` 처리 중 저장된다
- [ ] 직후 글은 다음 `/draft`(다음 질문 또는 제출 때) 글로 채워진다
- [ ] 저장 형식은 6장 데이터 구조를 따른다 (시연용 JSON 파일)

### P0-6. 교사 리포트: 메모 + 전후 비교

- [ ] 제출된 글에 질문한 위치마다 여백 메모가 붙는다 (도토리 번호·시간·질문·분류)
- [ ] 메모를 클릭하면 펼쳐진다: AI 답, 질문 직전 글, 질문 직후 글
- [ ] 전후 비교에서 추가는 초록, 삭제는 빨강으로 표시된다
- [ ] 학생 화면에서는 메모가 보이지 않는다

### P1-1. 질문 자동 분류

- [ ] 7장 지시문 ②로 질문을 분류한다
- [ ] 결과가 JSON(stage / type / reason)으로 저장된다
- [ ] stage는 5종(계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기) 중 하나다
- [ ] type은 4종(사실 확인 요청 / 생각 확장 요청 / 글 점검 요청 / 대신 작성 요청) 중 하나다
- [ ] 교사 리포트 메모에 분류가 표시되고, 학생 화면에는 보이지 않는다
- [ ] JSON 파싱 실패 시 처리: TBD(확인 필요)

### P1-2. 개요 단계 / 성찰지 단계

- [ ] 개요 4항목(주제·배경지식 / 문법·어휘 / 해석과 근거 / 비평과 고쳐쓰기)을 입력·저장할 수 있다 (`POST /outline`)
- [ ] 개요 표에 항목별 도토리 수가 표시되고, 글쓰기 단계 질문 시 자동으로 쌓인다
- [ ] 성찰지 왼쪽에 개요 항목별 도토리 막대그래프가 자동으로 그려진다
- [ ] 성찰 질문 ①~④에 답을 입력하고 제출할 수 있다 (`POST /submit`)

### P1-3. 작성 경로 색 표시

- [ ] 교사 리포트에서 문장마다 3가지 중 하나로 색 표시된다: 스스로 작성 / 질문 후 수정 / AI 답변 활용
- [ ] 질문 직후 새로 생긴 문장을 AI 답과 비교(유사도 또는 지시문 ③)해 판정한다
- [ ] 유사도 기준값과 3가지 색: TBD(확인 필요)
- [ ] 학생 화면에는 보이지 않는다

### P2 (발표에서 설명만 — 구현하지 않음, 시간 남으면 구현)

- [ ] 반 전체 집계: 발표 자료에 설명 포함
- [ ] 슈퍼스쿨 연동: 발표 자료에 설명 포함 (바로가기 **링크**는 2장·9장 시연에 사용 → 확인 필요 목록 참고)
- [ ] 페이스페이 실연동: 발표 자료에 설명 포함 (시연은 모의 화면)
