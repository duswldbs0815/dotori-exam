## 완료 기준 체크리스트

### P0-1. 글쓰기 + 질문창

- [ ] 학생이 글쓰기 창에 글을 쓸 수 있다
- [ ] 글을 드래그해 선택하면 선택한 글과 함께 질문을 보낼 수 있다 (드래그 없이도 질문 가능: `selectedText: ""`, `selection: null`)
- [ ] 선택 위치가 `selection: { start, end }`로 전송된다
- [ ] 질문할 때 개요 항목(①~④)을 고를 수 있다
- [ ] 질문할 때 현재 글 전체를 `draft`로 함께 보낸다
- [ ] 글쓰기 단계에서 10초마다 `POST /api/draft`로 자동 저장한다
- [ ] 화면 배치: 왼쪽 글쓰기 창 / 오른쪽 위 질문 쓰기 / 가운데 나의 질문 기록 / 아래 도토리 창고

### P0-2. 도토리 차감 + 창고 애니메이션

- [ ] 질문 전 "도토리 1개를 사용할까요?" 확인창이 뜬다 (목표를 넘겨도 같은 확인창 하나만)
- [ ] 사용하면 도토리가 정확히 1개 차감된다 (`charged: true`)
- [ ] 창고의 도토리가 넘어지는 효과가 보인다 (차단이면 넘어지지 않음)
- [ ] 항목별로 `사용 3 / 목표 2`처럼 숫자를 보여 준다. 목표를 넘겨도 경고 창 없이 계속 질문할 수 있다
- [ ] 장난 방지 안전장치(100번, 학생에게 안 보임) 도달 시 429 메시지를 보여 준다
- [ ] 화면은 숫자를 직접 쓰지 않고 `exam/start` 응답의 `exam` 값을 쓴다

### P0-3. AI 답변

- [ ] 서버가 LLM을 호출해 답을 받아 학생 화면에 표시한다
- [ ] 글·문단·문장을 대신 쓰거나 학생 문장을 고쳐 쓰지 않는다
- [ ] 답에 마크다운 기호가 없다
- [ ] 🔄 답변은 최대 세 문장, 해요체

### P0-4. 대신 작성 차단

- [ ] "감상문을 써 주세요" 같은 요청에 되묻기 문구가 나온다
- [ ] 답변 AI의 `[BLOCKED]` **또는** 분류 결과 "대신 작성 요청"이면 차단한다
- [ ] 차단 시 도토리가 차감되지 않는다 (`charged: false`, `acornNo: null`)
- [ ] 학생 화면에 `[BLOCKED]` 표식이 보이지 않는다
- [ ] 차단된 질문도 기록되어 리포트의 `blockedCount`에 잡힌다

### P0-5. 흔적 저장

- [ ] 질문마다 저장: 위치(`selectedText`, `selection`), 시간, 개요 항목, 질문, 답, 차단 여부, 도토리 사용 여부, 목표 초과 여부, 분류, 직전 글
- [ ] 직후 글은 "다음 질문의 직전 글, 마지막이면 제출한 글"로 리포트에서 계산된다
- [ ] 제출 후에는 질문과 글 저장이 막힌다

### P0-6. 교사 리포트: 메모 + 전후 비교

- [ ] 제출된 글에서 각 질문의 `selectedText`를 찾아 그 옆에 여백 메모를 붙인다. 못 찾으면 글 맨 끝 여백에 붙인다
- [ ] 메모: 도토리 번호·시간·질문·분류
- [ ] 메모를 클릭하면 AI 답, 직전 글, 직후 글이 펼쳐진다
- [ ] `diff`의 `add`는 초록, `del`은 빨강으로 표시한다
- [ ] 항목별 목표 vs 실제 사용, 차단 수가 보인다
- [ ] 학생 화면에서는 메모가 보이지 않는다

### P0-7. 개요 단계 (4항목 + 도토리 목표)

- [ ] 개요 4항목(주제·배경지식 / 문법·어휘 / 해석과 근거 / 비평과 고쳐쓰기)을 입력한다
- [ ] 항목마다 도토리 목표(0~10)를 정한다
- [ ] 개요·목표 없이 질문하면 409 메시지가 나온다
- [ ] 첫 질문 전까지는 고칠 수 있고, 첫 질문 이후에는 목표가 잠긴다 (개요 글은 계속 저장 가능)
- [ ] 새로고침하면 `GET /api/attempt/:attemptId`로 상태가 돌아온다

### P0-8. 성찰지 단계

- [ ] 개요 항목별 **목표 vs 실제** 막대그래프가 자동으로 그려진다
- [ ] 성찰 질문 ①~④에 답을 입력한다
- [ ] 제출 직전 `POST /api/draft`로 글을 저장하고 `POST /api/submit`으로 제출한다

### P1-1. 질문 자동 분류

- [ ] stage 5종, type 4종 중 하나로 저장된다 (목록 밖이면 `null`)
- [ ] 분류 실패해도 질문 처리는 계속된다
- [ ] 교사 리포트에만 보인다

### P1-2. 작성 경로 색 표시

- [ ] 제출 글의 문장마다 `self` / `revised` / `ai` 중 하나로 색 표시한다
- [ ] `revised`·`ai` 문장은 관련 도토리 번호(`acornNo`)를 함께 보여 준다
- [ ] 3가지 색: TBD(확인 필요)
- [ ] 학생 화면에는 보이지 않는다
