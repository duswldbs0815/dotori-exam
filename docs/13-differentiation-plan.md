# 13. 차별점과 "교사 일이 두 번 되는 문제" — 계획 (11/14)

> 한 줄 요약: 도토리 시험지는 **AI 사용 여부를 따로 평가하는 도구가 아니라, 교사가 원래 하던 수행평가 채점을 이 화면 하나에서 끝내게 하는 도구**여야 한다. 과정 기록은 별도 점수가 아니라 **채점 근거와 생기부 문장의 재료**로 들어간다.

## 문제: 지금 구조로는 일이 두 번

```
교사: 결과물 채점 (원래 하던 일, 학교 양식·나이스)
  +  의심 학생은 도토리 리포트·타임랩스 확인 (새로 생긴 일)
  +  둘을 머릿속에서 합쳐 최종 판단
```

- 서비스가 "AI 활용 리포트"를 **따로** 주면, 교사는 채점표와 리포트를 오가며 두 번 본다.
- 그리고 서비스가 "이 학생은 AI 의존"처럼 **판정**을 내리면, 평가 주체가 교사에서 서비스로 넘어가는 것처럼 보인다 (책임·공정성 문제).

## 원칙

1. **판정하지 않고 근거만.** 서비스는 점수나 "부정행위" 판정을 내지 않는다. "언제 무엇을 물었고, 그 뒤 글이 어떻게 바뀌었는지"라는 사실만 보여 준다.
2. **채점은 한 번, 한 화면에서.** 교사가 올린 채점기준표 항목 옆에 그 항목의 과정 근거(질문·전후 비교·타임랩스 구간)가 붙는다. 교사는 원래대로 점수만 매긴다.
3. **결과는 학교가 쓰는 모양으로.** 채점 결과 + 과정 근거 → 나이스 입력용 표(CSV)와 **세특(세부능력 및 특기사항) 초안**. 교사가 따로 정리할 일을 없앤다.
4. **전부 보지 않게.** 30명 리포트를 다 열지 않아도 되도록, 확인이 필요한 학생·구간만 먼저 띄운다.

## 차별점 (다른 조와 겹치지 않는 부분)

| | 흔한 접근 | 도토리 시험지 |
|---|---|---|
| AI 사용 확인 | AI 탐지기, 표절 검사 (정확도 낮음) | 시험지 안 AI만 쓰게 하고 **질문 하나하나를 기록** |
| 밖에서 쓴 AI | 못 잡음 | **타임랩스**: 10초 단위 글 변화. 한 번에 수백 자가 생기는 "붙여 넣기 구간"이 그대로 보임 (판정 없이 구간만 표시) |
| AI 답 활용 | 결과만 봄 | 질문 직후 글이 어떻게 바뀌었는지 전후 비교 + 영상처럼 다시 보기 |
| 교사 일 | 리포트를 하나 더 봄 | 채점기준표 옆에 근거가 붙어 **채점 한 번**, 세특 초안까지 |
| 학생 쪽 | 감시 | 도토리 계획 → 성찰 → 마이페이지 성장. 학생이 자기 AI 사용을 돌아보는 **메타인지 학습** |

발표 한 문장: **"AI를 잡아내는 대신, 과정을 보여 주고, 그 과정이 그대로 채점 근거와 생기부가 됩니다."**

## 교사 흐름 (바꾼 뒤)

```
수업 끝 → 반 화면
  ① 확인 필요 학생 3명 (붙여 넣기 구간, 차단 반복, 계획보다 훨씬 많은 질문)
  ② 학생 채점 화면 = [학생 글] + [채점기준표 항목별 점수 칸]
        항목 옆: 그 항목에서 한 질문, 전후 비교, 타임랩스 해당 구간 버튼
  ③ 점수 입력 → 세특 초안 자동 (교사가 고쳐서 확정)
  ④ 반 전체 → 나이스용 CSV / 슈퍼스쿨 보내기
```

## 구현 순서

| 순서 | 기능 | 상태 |
|---|---|---|
| 1 | **타임랩스**: 10초 저장 글을 변화분으로 쌓기, 교사 리포트에서 슬라이더로 다시 보기, 질문 시점 도토리 표시, 붙여 넣기 구간 표시 | 🔄 11/14 구현 |
| 2 | 채점 칸 (교사 리포트 안, 단계는 교사가 선택) | 🔄 11/14 구현 |
| 3 | 항목별 과정 근거 연결 (개요 항목 = 채점 항목, 도토리 누르면 타임랩스 이동) | 🔄 11/14 구현 |
| 4 | 세특 초안 (점수 + 과정 근거로 AI가 초안, 교사 확정). LLM 크레딧 필요 | 다음 |
| 5 | 확인 필요 학생 먼저 보기 (반 화면) | 🔄 11/14 구현 |
| 6 | 반 채점표 CSV 내보내기 | 🔄 11/14 구현 |

## 확인 필요

- 채점기준표를 몇 단계로 받을지 (예: 상·중·하 / 점수)
- 세특 초안에 AI 사용 이야기를 넣을지 (학생에게 불리하게 쓰이지 않도록 "질문하며 스스로 고친 과정" 같은 긍정 사실 위주로 쓸지)
