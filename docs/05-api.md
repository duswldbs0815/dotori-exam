## 엔드포인트 목록

| API | 하는 일 | 우선 | PDF 대비 |
|---|---|---|---|
| `POST /api/exam/start` | 응시 시작 (학번·이름) 🔄 `verified` 삭제 | P0 | 🔄 `/api` 접두어. "첫 글 저장"은 하지 않음 |
| `POST /api/outline` | 개요 4항목 + **항목별 도토리 목표** 저장 | P0 | 🔄 도토리 목표 추가. 첫 질문 이후 목표는 잠김 |
| `POST /api/draft` | 글 저장 (**10초마다** + 제출 직전) | P0 | 🔄 호출 주기 확정 |
| `POST /api/ask` | 질문 처리 (아래 순서) | P0 | 🔄 차단을 두 겹으로 판별, 답변 최대 세 문장 |
| `GET /api/attempt/:attemptId` | 학생 화면 상태 복원, 항목별 목표·사용 수 | P0 | 🆕 PDF에 없던 API |
| `POST /api/submit` | 최종 글과 성찰지 제출 (제출 후 질문·저장 막힘) | P0 | 같음 |
| `GET /api/report/:studentId` | 교사용 학생 리포트 (메모, 전후 비교, 작성 경로) | P0 | 같음 |
| `GET /api/report/class` | 교사용 반 전체 집계 | P2 | 서버 코드는 있음 |

공통 규칙 (API.md 기준):

- 요청·응답은 JSON. 실패하면 HTTP 4xx/5xx와 `{ "error": "사람이 읽을 메시지" }`
- 시험은 하나로 고정: 「진달래꽃」 감상문 쓰기 (`src/lib/exam-config.ts`)
- `attemptId`는 학생 ID와 같음 (예: `S07`)
- 🔄 학생 API(`outline`·`draft`·`ask`·`attempt`·`submit`)는 `exam/start`가 준 학생 열쇠 쿠키가 있어야 함. 없으면 403 (자세한 내용은 `API.md`)
- **학생 화면 응답에는 분류(stage, type), 작성 경로, 전후 비교를 넣지 않는다.** 교사 리포트 API에서만 내려간다.

## `/api/ask` 처리 순서

프론트는 **"도토리 1개를 사용할까요?" 확인을 받은 뒤** 호출한다. 목표를 넘겼는지와 상관없이 확인창은 이것 하나만 쓴다.

1. **상태 확인** — 응시 기록이 없으면 404, 이미 제출했으면 409, 개요·도토리 목표가 없으면 409 ("개요와 도토리 계획을 먼저 작성해 주세요."), 안전 상한(30번)에 도달했으면 429 ("이번 시험에서 질문할 수 있는 횟수를 모두 썼어요.")
2. **답변 생성 + 질문 분류를 동시에** 실행 (LLM 2번 호출)
3. **차단 판별** — 다음 중 하나면 차단
   - 답변 AI가 첫 줄에 `[BLOCKED]`를 씀
   - 분류 결과 `type`이 "대신 작성 요청"
4. **차단이면** 되묻기 문구로 답하고 **도토리를 쓰지 않음** (`charged: false`, `acornNo: null`)
5. **직전 글 저장** — 요청의 `draft`를 그 질문의 `before`로 저장 (현재 글로도 저장)
6. **도토리 차감** — 그 개요 항목의 사용 수 +1. 목표를 넘겼으면 `overPlan: true`로 **기록만** 하고 질문은 막지 않음

차단된 질문도 기록은 남는다 (분류·직전 글 포함). 반 전체 "차단된 요청 수"와 교사 메모에 쓰인다.

## PDF 대비 달라진 점

| 항목 | PDF 5장 | 지금 (지윤 결정) |
|---|---|---|
| 경로 | `/ask` 등 | `/api/ask` 등 (Next.js API Route) |
| 처리 순서 | 차단 판별 → 답변 → 분류 → 직전 글 저장 → 차감 | 답변·분류 동시 실행 → 둘 중 하나라도 차단이면 차단 → 직전 글 저장 → 차감 |
| `/exam/start` | 첫 글 저장 포함 | 본인 확인 기록만. 글은 `/api/draft`와 `/api/ask`에서 저장 |
| 도토리 | 질문 1번 = 1개 (총개수 미정) | 질문 1번 = 1개는 같음. 총개수를 정하지 않고 학생이 항목별 목표를 세움. 안전 상한만 있음 |
| 학생 상태 조회 | 없음 | `GET /api/attempt/:attemptId` 추가 |
