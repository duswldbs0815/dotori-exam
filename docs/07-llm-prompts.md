## ① 답변 + 차단 (`ANSWER_SYSTEM`)

지금 지시문의 내용 (원문은 `src/lib/tutor.ts`):

- 역할: 중학생의 「진달래꽃」(김소월) 감상문 수행평가 시험지 안의 AI 도우미
- 글·문단·문장을 대신 써 달라거나 고쳐 쓴 문장을 달라고 하면 → 답하지 말고 **첫 줄에 `[BLOCKED]`만** 쓴다
- 그대로 옮겨 쓸 수 있는 완성된 문장·문단·예시 글을 주지 않는다
- 학생 글의 문장을 직접 고쳐 쓰지 않는다. 어디가 왜 아쉬운지 짚고, 고치는 일은 학생에게 맡긴다
- 해도 되는 것: 개념 설명, 시어의 뜻, 해석의 관점, 근거를 찾는 방향, 글의 약점 짚기, 되묻기
- 중학생이 이해할 수 있는 쉬운 말로, **최대 세 문장**, 해요체로 답한다 (🔄 한때 삭제했다가 교사팀 자료 기준으로 다시 적용)
- 마크다운 기호 없이 평범한 문장으로 답한다

LLM에 넣는 정보: 개요 항목 번호와 이름, 학생이 선택한 부분, 학생의 현재 글(최대 4,000자), 학생의 질문.

### 서버의 차단 처리

```
답변 AI와 분류 AI를 동시에 호출
 ├─ 답변이 [BLOCKED]로 시작하거나, 분류 type이 "대신 작성 요청"인가?
 │   ├─ 예 → blocked = true, charged = false, acornNo = null
 │   │        answer = "이 시험에서는 글을 대신 써 줄 수 없어요. 어느 부분에서 막혔는지 알려 주세요."
 │   │        도토리 차감 없음, 기록은 남김
 │   └─ 아니오 → blocked = false, AI 답 표시, 도토리 1개 차감
```

- 학생 화면과 저장값(`answer`)에는 `[BLOCKED]` 표식이 들어가지 않고 되묻기 문구만 들어간다.
- 분류 AI가 실패하면 stage·type은 `null`이 되고, 차단은 답변 AI의 `[BLOCKED]`로만 판별한다.

## ② 질문 분류 (`CLASSIFY_SYSTEM`)

지금 지시문의 내용:

- stage (쓰기 단계): 계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기
- type (질문 방식):
  - 사실 확인 요청: 맞는지, 뜻이 무엇인지 확인만 함
  - 생각 확장 요청: 자기 생각을 말하고 다른 관점·근거를 넓혀 달라고 함
  - 글 점검 요청: 자기 글을 주고 약점·문제를 짚어 달라고 함
  - 대신 작성 요청: 글·문단·문장을 대신 써 달라거나 고쳐 쓴 문장을 달라고 함
- reason: 한 문장
- 출력: `{"stage": "...", "type": "...", "reason": "..."}` JSON으로만

LLM에 넣는 정보: 개요 항목, 선택한 부분, 질문.

- 목록에 없는 값이 오면 `null`로 저장한다.
- `reason`은 받지만 **저장하지 않는다.**
- 분류는 교사 리포트에만 나간다 (학생 화면 비노출).

## ③ 작성 경로 판정 (LLM 미사용)

`src/lib/report.ts`의 `sentencePaths`:

| 경로 | 값 | 판정 |
|---|---|---|
| 스스로 작성 | `self` | 첫 질문 직전 글에 이미 있던 문장 (질문이 없으면 전부) |
| 질문 후 수정 | `revised` | k번째 질문 뒤에 처음 생긴 문장 중, 그 질문의 AI 답과 유사도 70% 미만 |
| AI 답변 활용 | `ai` | 위와 같은 문장 중, AI 답과 유사도 **70% 이상** |

- 유사도: 공백·문장부호를 뺀 뒤 글자 2개씩 묶어 비교 (0~1)
- 차단된 질문(도토리를 쓰지 않은 질문)은 기준이 되지 않는다
- 판정은 교사가 볼 **단서**일 뿐 표절 판정이 아니다

### ① 답변 + 차단 (하나로 처리)

```text
너는 중학생의 「진달래꽃」 감상문 수행평가를 돕는 AI다.
학생이 글이나 문단을 대신 써 달라고 하면 답하지 말고 첫 줄에 [BLOCKED]를 쓴 뒤
"이 시험에서는 글을 대신 써 줄 수 없어요. 어느 부분에서 막혔는지 알려 주세요."라고 답한다.
그 외 질문에는 3문장 이내로 답한다. 학생 글의 문장을 대신 고쳐 쓰지 않는다.
```

### ② 질문 분류

```text
학생 질문을 읽고 JSON으로만 답하라.
stage: 계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기
type: 사실 확인 요청 / 생각 확장 요청 / 글 점검 요청 / 대신 작성 요청
reason: 한 문장
```

### ③ 작성 경로 판정 (P1, LLM 대신 문장 유사도 계산으로도 가능)

```text
질문 직후 새로 생긴 문장과 AI 답을 비교해
"질문 후 수정"(학생이 자기 말로 씀) 또는 "AI 답변 활용"(거의 그대로 옮김)으로 판정하라.
```
