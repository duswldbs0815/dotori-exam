## ① 답변 + 차단 (하나로 처리) — P0

```text
너는 중학생의 「진달래꽃」 비평문 수행평가를 돕는 AI다.
학생이 글이나 문단을 대신 써 달라고 하면 답하지 말고 첫 줄에 [BLOCKED]를 쓴 뒤
"이 시험에서는 글을 대신 써 줄 수 없어요. 어느 부분에서 막혔는지 알려 주세요."라고 답한다.
그 외 질문에는 3문장 이내로 답한다. 학생 글의 문장을 대신 고쳐 쓰지 않는다.
```

### 출력 형식

| 경우 | 출력 |
|---|---|
| 대신 작성 요청 | 첫 줄 `[BLOCKED]` + 되묻기 문구 |
| 그 외 | 3문장 이내 답 (첫 줄에 `[BLOCKED]` 없음) |

```text
// 차단 시 예상 출력 형태 (지시문에서 도출)
[BLOCKED]
이 시험에서는 글을 대신 써 줄 수 없어요. 어느 부분에서 막혔는지 알려 주세요.
```

- 학생 질문·선택한 글·현재 글을 LLM 메시지에 어떻게 넣는지(입력 형식): TBD(확인 필요)

### 서버의 `[BLOCKED]` 처리

```
LLM 응답 수신
 ├─ 첫 줄이 [BLOCKED] 인가?
 │   ├─ 예 → blocked = true
 │   │        학생에게 되묻기 문구 표시
 │   │        도토리 차감 없음
 │   │        기록은 남김 (반 전체 "차단된 요청 수" 집계)
 │   └─ 아니오 → blocked = false
 │            답 표시, 도토리 1개 차감
```

1. 응답 첫 줄이 `[BLOCKED]`이면 `blocked: true`로 기록한다.
2. 학생에게는 되묻기 문구("이 시험에서는 글을 대신 써 줄 수 없어요. 어느 부분에서 막혔는지 알려 주세요.")를 보여 준다.
3. **도토리를 차감하지 않는다.** (4장 P0 "대신 작성 차단": 차단 시 답 대신 되묻기, 도토리 차감 없음 / 9장 시연: "차단, 도토리 그대로")
4. 차단 질문도 기록한다 — 교사 리포트 반 전체에 "차단된 요청 수"가 있음.

- `[BLOCKED]` 줄을 학생 화면에 보여 줄 때 제거하는지: TBD(확인 필요, 제거가 자연스러움)
- `answer` 필드에 `[BLOCKED]`까지 저장하는지: TBD(확인 필요)

## ② 질문 분류 — P1

```text
학생 질문을 읽고 JSON으로만 답하라.
stage: 계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기
type: 사실 확인 요청 / 생각 확장 요청 / 글 점검 요청 / 대신 작성 요청
reason: 한 문장
```

### 출력 형식

JSON 객체. 키 3개:

| 키 | 값 |
|---|---|
| `stage` | 계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기 중 하나 |
| `type` | 사실 확인 요청 / 생각 확장 요청 / 글 점검 요청 / 대신 작성 요청 중 하나 |
| `reason` | 한 문장 |

- 6장 JSON에는 `stage`, `type`만 있고 `reason` 필드가 없음 → 저장 여부 TBD(확인 필요)
- 결과는 교사 리포트에만 표시 (학생 화면 비노출)
