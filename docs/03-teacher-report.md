# 03. 교사 리포트 화면

> 한 줄 요약: 교사 리포트는 학생 글에 질문 위치마다 여백 메모를 달고, 메모를 누르면 AI 답과 질문 전후 비교(추가 초록/삭제 빨강)를 펼치며, 문장별 작성 경로 3종과 반 전체 집계를 보여 줍니다. (PDF 3장)
>
> 관련 문서: [02-student-screens](./02-student-screens.md) · [05-api](./05-api.md) · [06-data-model](./06-data-model.md) · [07-llm-prompts](./07-llm-prompts.md)

## 화면 영역

| 영역 | 내용 | 우선순위 (4장) |
|---|---|---|
| 학생 글 보기 | 제출된 글 + 질문한 위치마다 **여백 메모** (도토리 번호 · 시간 · 질문 · 분류) | P0 (분류 표시는 P1) |
| 메모 클릭 | 그 질문의 **AI 답**, **질문 직전 글**, **질문 직후 글** (추가 **초록**, 삭제 **빨강**) | P0 |
| 작성 경로 | 문장마다 색 표시: **스스로 작성 / 질문 후 수정 / AI 답변 활용** | P1 |
| 반 전체 | 쓰기 단계 × 질문 방식 표, 개요 항목별 도토리 합계, 차단된 요청 수 | P2 |

- 교사 리포트 진입: 슈퍼스쿨 교사 홈 **바로가기 링크** (2장)
- API: `GET /report/:studentId`, `GET /report/class` ([05-api](./05-api.md))

## 1. 학생 글 + 여백 메모

여백 메모에 표시하는 항목 → 데이터 필드 대응 ([06-data-model](./06-data-model.md)):

| 메모 항목 | 필드 |
|---|---|
| 도토리 번호 | `questions[].acornNo` |
| 시간 | `questions[].time` |
| 질문 | `questions[].question` |
| 분류 | `questions[].stage`, `questions[].type` |
| 위치 (메모가 붙는 곳) | `questions[].selectedText` (+ 시작·끝 위치, 8장) |

- 메모 위치는 **질문한 위치**. 질문 이후 글이 바뀌어 제출된 글에서 위치가 달라지는 경우의 처리: TBD(확인 필요)
- 차단된 질문도 메모로 표시하는지: TBD(확인 필요)

## 2. 메모 클릭 → 전후 비교

```
[메모 클릭]
 ├─ AI 답            ← questions[].answer
 ├─ 질문 직전 글      ← questions[].before
 └─ 질문 직후 글      ← questions[].after
     · 추가된 부분: 초록
     · 삭제된 부분: 빨강
```

- 전후 비교는 diff 라이브러리 사용 (예: diff-match-patch, 8장)
- 단위(글자/단어/문장): TBD(확인 필요)

## 4. 반 전체 집계 (P2)

| 집계 | 형태 |
|---|---|
| 쓰기 단계 × 질문 방식 | 표 (행: stage 5종, 열: type 4종 — 7장 ② 기준) |
| 개요 항목별 도토리 합계 | 항목 ①~④별 합계 |
| 차단된 요청 수 | 개수 |

stage: 계획하기 / 내용 생성 / 내용 조직 / 표현하기 / 고쳐쓰기
type: 사실 확인 요청 / 생각 확장 요청 / 글 점검 요청 / 대신 작성 요청
